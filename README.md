# Envelope Visible Delay Effect

两个基于 **Web Audio API** 的交互式效果器演示。全部是单文件 HTML，无需任何依赖，双击即可在浏览器（推荐 Chrome / Edge）中打开运行。

---

## 1. TC Electronic 2290 · Trig / Env 包络触发可视化

文件：`tc2290-trig-env.html`

还原传奇数字延迟 **TC Electronic 2290** 的 `ENV`（包络跟随）与 `TRIG`（阈值触发）逻辑，并把「输入电平 → 包络 → 调制延迟时间 / 阈值触发复位 LFO」这一整套操控过程可视化。

- 点击钢琴发声（支持键盘 A–K），声音送入延迟效果器
- 实时显示：输入波形、包络曲线、延迟时间调制、包络→延迟时间传递曲线
- 支持：Pad 持续模式、干湿交叉淡化（可调出颤音 / flanger / chorus）、键盘键入参数

## 2. Harmonic Tremolo 谐波颤音

文件：`harmonic-tremolo/index.html`

把信号**分频**成高 / 低两路，再用**相位相反（相差 180°）**的颤音波形分别调制两路，实现"明暗交替"的音色调制，比普通颤音更有律动与色彩。

- 低通 / 高通分频（分频点可调）
- 反相颤音调制（速率 / 深度 / 波形）
- 实时显示：两路反相颤音曲线、分频曲线、输入波形、低/高频电平表
- 支持 Pad 持续模式、键盘键入参数

---

## 使用

直接用浏览器打开对应的 HTML 文件，点击琴键或按键盘 A–K 发声即可。
